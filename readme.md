🎪 即時現場建構與舞台視覺系統 (Stage & Backdrop Live Visualizer Pro)
  這是一套專為活動企劃、展覽硬體工程師、視覺設計師打造的即時場地虛擬建構與預估系統。無需安裝任何重量級軟體或 3D 建模工具，透過瀏覽器即可在活動現場與客戶進行即時繪圖溝通，迅速調整結構配置，並一鍵匯出符合施工標準的專業黑白工程藍圖。

🌟 核心功能特色
1. 雙重結構用途一鍵切換
專業舞台系統：支援自訂舞台面寬、地台高度、結構深度，並可自由配置防滑舞台面板與安全階梯。
活動打卡牆 / 視覺牆：自動隱藏舞台面板，將地台高度降至極薄的  地端底座，並於 3D 視角中自動生成後方 A 字防風斜撐支撐架與配重沙包，完全符合現場施工的安全配置。
2. 「無階梯」舞台配置彈性
新增一鍵開啟/關閉登台安全階梯之開關。
關閉階梯後，2D 正視圖、3D 立體圖與 BOM 材料清單中的階梯數量與租賃估算將同步歸零，方便針對特殊無落差場地進行預算評估。
3. 多視角 2D/3D 互動渲染
2D 正視圖：提供精確的尺寸標註與工程參考網格，支援滑鼠/手勢直接拖曳背板以調整離地高度 ()。
3D 立體圖：採用純幾何矩陣投影算法，支援 360 度滑鼠/觸控手勢自由旋轉與無段縮放，全方位檢視 A 字後支撐架設細節。
4. 智慧型 BOM 施工物料與預算即時估算
系統會根據 2D/3D 的外框寬高與地台尺寸，自動拆解並計算所需桁架（Truss）規格（包含 2 米直管、1 米微調管、六向轉角箱、鋼製重型底座、舞台防滑板或打卡牆專用後斜撐、階梯數量）。
支援自主修改單項硬體每日租賃單價，即時統計總預算與預估搭設工時。
5. 專業高階白底黑線藍圖匯出
徹底解決文字重疊壓圖問題：採用上下分割式專業圖紙排版（上半部為 2D/3D 結構渲染，下半部為三欄式工程規格與施工備註表）。
移除備註框線，呈現極簡、現代化的建築藍圖風格。
內建中英文混排自動折行（Auto Wrap）字元計算引擎，確保現場施工備註在匯出的  圖紙中絕對不跑版。
